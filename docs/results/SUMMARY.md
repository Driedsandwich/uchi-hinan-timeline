# B3 家族の約束：変更点と検証結果

B3案の版の変更点と検証結果の控えです。この検証の時点では外部への公開・デプロイは行っていません。

## 変更した内容

結果画面を先に調整し、「この家の危険」「避難先候補」の2枠、家族別の大きな名前と行動、共通のレベル4・5という順番へ変更しました。PCでは家族を2列、スマホでは縦積みにしています。レベル3は赤 #FF2800、4は紫 #AA00AA、5は黒 #000000。色に加えて数字・名称・発令時・行動を記載しました。

入力・確認も青 #1746C8、白、黒枠2px、角丸12pxに統一しました。最初のPC画面に作品の目的と「見本で試す」を表示。聞き返しは実際に返った質問を番号付きカードにし、既存の入力・確認処理を維持しています。

「家族へ送る」は見出し直下に置きました。押すと内容を確認するダイアログが開き、その中で共有リンク作成・文のコピーを行います。外部サービスへ送信する機能は追加していません。共有リンクの形式とAPIを呼ばない復元処理も維持しました。

A4は共有操作を外し、家族カード、支援者、レベル4・5、持ち物、連絡先を載せています。名前36pt、主行動28pt、タイトル32ptを維持し、標準3見本を各1ページにしました。家族が多い場合や長文では、文字を縮めず改ページします。

見本画像の数値・学校・付き添う「私」は流用していません。作品の実データから表示し、支援者未定、父の時間未計算、区域未取得も残しました。元の計画文・判定理由・災害ごとの値・出典URL・取得日時・移動時間の前提は画面下部で確認できます。「事前の計画」「発令時」と見本表示を保持しています。

フォントは端末の Noto Sans JP / Noto Sans CJK JP / sans-serif。外部フォント通信・新規依存はありません。撮影環境では端末にある Noto Sans CJK JP を使用しています。
