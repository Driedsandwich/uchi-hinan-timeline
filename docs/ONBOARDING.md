## 見本の仕組み

`src/data/sample-plans.json` に3例を同梱しています。`scripts/prepare-samples.ts` が、元からある `tests/fixtures/public-record.json`、PNG、避難先GeoJSON、`src/core/samples.ts` の架空の家族を使い、**既存の** `mockExtract` と `buildPlan` を実行して作成しました。判定・計算・文章検査は複製せず、既存のものをそのまま使っています。記録時刻は2026年11月6日（日本時間）。存在しない記録の隣接タイルは取得不能のままで、安全・全範囲取得とは表示しません。候補の出典URLは同梱GeoJSONの実際の出典を保持しています。

見本の内容は固定です。確認画面は読み取り専用で、実際の入力は通常のAPI経路を通ります。見本ではAPIの作成回数制限を消費せず、実入力の署名・回数制限は従来のままです。画面の初期表示時にはAIの有効状態を確かめるGETだけが発生します（AI呼び出しなし）。共有された計画の表示は従来どおりAPI通信なしです。

見本の再生成（外部通信・AI呼び出しなし）：

```sh
npx tsx scripts/prepare-samples.ts
```
